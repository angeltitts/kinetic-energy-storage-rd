# Project Brief

## Mission
Develop or falsify a manufacturable high-specific-energy kinetic energy storage architecture.

The current concept is the **Differential Slip-Hoop Cell (DSHC)**.

## Core architecture
- Thin, circumferential high-strength hoops as the primary storage medium.
- Multiple independently rotating radial zones.
- Minimal radial structural load transfer between hoops.
- High vacuum.
- Shaftless electromagnetic torque transfer.
- HTS flux-pinned suspension located in a magnetic quiet zone.
- Electrical regenerative emergency dump as the first safety response.
- Passive electromagnetic braking as the second response.
- Sacrificial close-clearance containment as the final residual-energy absorber.

## Governing thin-hoop relations

For an ideal thin hoop:

    sigma = rho * v^2

    e_rotor = sigma / (2*rho)

where:
- sigma = usable hoop tensile stress [Pa]
- rho = rotor density [kg/m^3]
- v = peripheral velocity [m/s]
- e_rotor = specific energy [J/kg]

Angular speed:

    omega = v / r

RPM:

    rpm = omega * 60 / (2*pi)

## Current breakthrough targets
1. Macroscale high-specific-strength fiber material.
2. Stable rotordynamics at multi-km/s peripheral speeds.
3. Graceful/progressive failure containment with low parasitic mass.

## Current system targets
- Phase 0 feasibility gate: >= 500 Wh/kg system
- Advanced target: >= 1,000 Wh/kg system
- Long-range research target: 2,000–3,500 Wh/kg system

## Explicitly discarded unless new quantitative evidence appears
- Plasma kinetic storage
- Primary SMES
- Thick monolithic CNT torus
- Electrochemical storage inside the rotor/vacuum/cryo module
- Full-energy thermal ablation as the intended emergency stop
- Large radial/transverse stress-bearing composite matrix
- SMES transient buffer as a default subsystem

## Engineering philosophy
The project is not obligated to prove DSHC works.
The project is obligated to determine whether it works.
