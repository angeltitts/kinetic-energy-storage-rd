# Results

`baseline.json` is the committed deterministic Phase 0 baseline.

`phase0_sweep.csv` is generated by `python models/parameter_sweep.py` and uploaded by the GitHub Actions workflow as an artifact. It remains intentionally uncommitted because it is a large exploratory sweep rather than a narrative-table backing file.

The following Phase 1-3 CSVs are **committed** because they are small, deterministic, and directly back the values reported in the corresponding Markdown result tables:

- `phase1_500whkg_gate.csv`
- `phase2_mass_budget.csv`
- `phase3_segmented_containment.csv`

CI regenerates and uploads all of these files as artifacts as an additional reproducibility check. `tests/test_results_docs_match_models.py` guards the representative narrative values against silent model/document drift.
