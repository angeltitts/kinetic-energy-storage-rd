# Kinetic Energy Storage R&D

Autonomous engineering R&D program for a high-specific-energy kinetic storage architecture.

## Current architecture
**DSHC — Differential Slip-Hoop Cell**

The program investigates whether a shaftless, vacuum-contained stack of thin high-specific-strength hoops can reach battery-class or beyond-battery-class **system-level** energy density while preserving high cycle life and power density.

## Phase 0 objective
Determine whether any DSHC configuration can exceed **500 Wh/kg system-level** using a hypothetical structural CNT material with:

- usable tensile strength: 20 GPa
- density: 1.5 g/cm^3

while explicitly accounting for:
- fatigue derating
- safety factor
- containment mass
- stator / motor-generator mass
- bearing and cryogenic mass
- vacuum enclosure mass
- power electronics mass

## Rule
Optimize **complete-system Wh/kg**, never rotor-only Wh/kg.

A negative result is a valid result.
